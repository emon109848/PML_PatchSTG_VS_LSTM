# Presentation files

- [presentation.pptx](presentation.pptx): main 23-slide talk, about 21 minutes plus questions.
- [presentation_detailed.pptx](presentation_detailed.pptx): same talk plus 21 optional explanation slides.
- [presentation.pdf](presentation.pdf): portable source-layout preview of the main talk.
- [presentation.md](presentation.md): slide outline and speaker notes.

The [final written report](../reports/final_comparison/PROJECT_REPORT.md) includes
the updated comparisons and the same plots. Figures and portable saved plot data
live under [reports/presentation](../reports/presentation/README.md).

Rebuild from the project root with `python scripts/build_presentation.py`.
This does not run any forecasting model. The PDF uses source-layout rendering;
check native PowerPoint fonts on the presentation PC. Earlier decks remain in
`temp/presentation_before_review_2026-11-21/` locally.
